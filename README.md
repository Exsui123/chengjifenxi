# 成绩分析系统

## 项目说明
这是一个纯前端的成绩分析网页系统，用于上传、存储和分析学生成绩数据。系统采用现代化的UI设计，提供直观的数据展示和分析功能。

## 技术栈
- HTML5
- CSS3
- JavaScript（纯原生，不使用框架）

## 系统功能模块

### 1. 数据上传模块
- 支持Excel/CSV文件格式上传
- 自动识别用户上传的数据（列标题为科目的格式）
- 上传后预览数据
- 为数据文件命名（名称、日期、班级）

### 2. 文件列表模块
- 展示已上传的数据文件
- 支持查看、删除文件操作

## 页面结构
- `index.html`: 主页面，包含系统导航和基本布局
- `styles/`: 样式文件夹
  - `main.css`: 主样式文件
  - `upload.css`: 上传模块样式
  - `filelist.css`: 文件列表样式
- `scripts/`: 脚本文件夹
  - `app.js`: 主应用逻辑
  - `upload.js`: 文件上传和预览功能
  - `storage.js`: 本地存储管理
  - `fileList.js`: 文件列表展示和管理

## 数据存储
由于是纯前端系统，数据将存储在浏览器的本地存储(localStorage)中。每个上传的文件将转换为JSON格式并保存。

## 使用说明
1. 点击"上传文件"按钮选择Excel或CSV文件
2. 系统会自动解析文件并显示预览
3. 确认数据无误后，输入文件名称、日期和班级信息
4. 点击"保存"按钮完成上传
5. 在"文件列表"页面可以查看所有已上传的文件

# 成绩分析系统

## 项目介绍

成绩分析系统是一个纯前端实现的数据分析工具，专为教师设计，用于管理、分析和可视化学生成绩数据。该系统不需要后端支持，所有数据存储在浏览器的本地存储中，保证数据的私密性和安全性。

## 功能特点

### 1. 数据上传
- 支持Excel(.xlsx, .xls)和CSV文件格式
- 拖拽上传与文件选择功能
- 提供标准Excel模板下载功能
- 数据预览与分页显示
- 文件基本信息（名称、日期、班级）设置

### 2. 文件管理
- 文件列表显示与管理
- 文件删除功能
- 分数线设置（及格线、良好线、优秀线）
- 设置保存到本地

### 3. 数据分析
- 基础指标分析（平均分、最高分、最低分、及格率等）
- 点击分数等级指标卡片（优秀率、良好率、及格率、不及格率）显示对应学生名单
- 个人成绩详情图表
- 个人成绩总结与学习优化建议
- 个人成绩变化趋势分析
- 多文件比较与数据可视化

## 技术架构

### 前端技术
- 纯HTML5、CSS3和JavaScript实现
- 响应式设计，适配不同设备屏幕
- 模块化开发，代码结构清晰

### 第三方库
- XLSX.js：用于解析Excel文件
- PapaParse：用于解析CSV文件
- Chart.js：用于绘制数据图表与可视化
- ChartDataLabels插件：增强图表数据标签显示

### 数据存储
- 使用浏览器localStorage进行本地数据存储
- 支持数据导入/导出功能

## 使用方法

1. 打开index.html启动应用
2. 上传成绩数据文件（Excel或CSV格式）
3. 设置文件名称、日期和班级信息
4. 在文件列表页面设置成绩分数线
5. 在数据分析页面选择分析类型，查看数据分析结果
6. 点击分数等级指标卡片（优秀率、良好率、及格率、不及格率），查看对应学生名单
7. 选择"个人成绩详情图"，查看学生个人成绩详情和学习优化建议

## 数据格式要求

上传的Excel或CSV文件应包含以下必要信息：
- 第一行为表头，必须包含：学号、姓名、语文、数学、英语
- 学号格式应为：01、02、03等数字格式（可以有前导零）
- 各科目分数应为数字格式

系统提供标准Excel模板下载，建议使用模板录入数据后上传，以确保数据格式正确。标准模板的列结构为：
- 学号：学生编号，如01、02、03等
- 姓名：学生姓名
- 语文：语文科目成绩
- 数学：数学科目成绩
- 英语：英语科目成绩

## 成绩总结与建议功能介绍

"个人成绩详情图"功能中新增了成绩总结与学习优化建议功能，包括以下内容：

1. **成绩总体分析**：概括学生的总体表现，包括排名情况和整体水平
2. **优势科目分析**：识别学生表现较好的科目，显示分数和与班级平均分的差距
3. **需加强科目分析**：识别学生需要提升的科目，分析与班级平均水平的差距
4. **科目具体建议**：针对每个科目提供个性化的学习建议，基于分数与及格线、良好线、优秀线的比较
5. **学习策略建议**：提供时间管理、学习方法、资源利用等方面的整体学习策略

该功能通过对学生成绩与班级整体数据的比较分析，生成个性化的学习改进建议，帮助学生有针对性地提高学习效果。

## 本地存储说明

系统使用浏览器localStorage存储以下数据：
- 文件数据：包含解析后的成绩数据和文件元信息
- 分数线设置：及格线、良好线和优秀线
- 个人偏好设置

## 浏览器兼容性

- Chrome 60+
- Firefox 55+
- Safari 11+
- Edge 80+

## 注意事项

- 由于使用本地存储，请不要清除浏览器缓存，否则数据将丢失
- 建议定期使用导出功能备份数据
- 大型数据文件（超过5MB）解析可能较慢，请耐心等待
